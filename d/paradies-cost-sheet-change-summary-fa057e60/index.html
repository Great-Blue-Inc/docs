02

What changed

Create Sample flow shots are from the live org, saved versions side by side. PDF renders are from a sandbox test sheet that uses the same page code as production.

Create Sample flow Flow Builder

Before (version 4). Three steps: the screen, the values, and the record create. When the record create failed, the user saw a generic unhandled fault message.

plain message on failure

After (version 5). A failed create now follows the Fault path (outlined in red) to a "Sample not created" screen with a plain explanation. Version 5 is the active version.

Create Sample screen screen editor

removed

Before (version 4). The screen asks for Due Date, Quantity, Where to Purchase, Size to Order, and Shopworx Order Number. The last field is outlined in red.

After (version 5). The same screen ends at Size to Order. Shopworx Order Number is gone.

Not visible in Flow Builder

The sample starting status ("NEW - To Be Entered") is set inside the create step. The approved-art requirement is a validation rule on the development item, now switched off, which is why Create Sample no longer stops without approved art.

Internal PDF cost sheet

Before. The previous page layout: Type, Detail, Treatments and Labeling as columns, with no Location, no shipping note and no Additional notes. This is a sandbox render of the previous page code.

After. Columns now read Type, Detail, Location, Treatments. Labeling has its own row. The shipping note and the Additional notes section appear under Samples. This is a sandbox render of the same page code that is live in production, with test data only.

Customer PDF unchanged

After, identical to before. The customer PDF has no Location column, no shipping note and no Additional notes section, and Labeling stays a column. A render from the previous page code on the same sheet matched this one exactly. The only customer-visible effect is the live comp on Draft sheets.
