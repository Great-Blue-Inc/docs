One bid, start to finish

1Open Bid Quoting and upload the spec book

In Salesforce, open the App Launcher (the grid of dots at the top left), type Bid Quoting and select it. The app opens on Your spec books. Select Upload a new spec at the top right. From an open draft, select Upload a spec in the left rail instead.

  • Select Choose a PDF, or drop a PDF on the box. Pick the Division 27 and 28 section of the spec book, not the whole project manual.
  • The app checks the PDF for Division 27 and 28 pages. Check the page range it shows, then select Use these pages.
  • If the range is wrong, type the pages under Or enter a different page range, for example 12-40, 88-95, and select Use this range. Process the whole file instead reads every page.

2Choose the run speed and start

Under Run speed on the upload card, pick the speed for this run only. Standard is picked for you. Fast runs one at a time and costs about twice as much. The note under each choice says how they differ. Then select Start upload.

The org default behind Standard

Standard follows one org setting. To see it, select Settings at the bottom of the left rail and find How matching is sent to the model under How this org works.

  • Batched (lower cost, takes longer): a Standard run is batched and lower cost.
  • One at a time (about twice the cost, returns sooner): a Standard run also goes one at a time. The note under Standard on the upload card then reads Your org setting: one at a time.
  • Only a person with the Spec Settings Admin permission set can change this and select Save changes. Everyone else can see the setting but not change it. The choice applies to everyone in the org.

3While it runs

The strip at the top shows each step of the run: Read, Find requirements, Match products, Price and Draft. The pill reads In progress. There is no need to wait on the page.

To come back later, select Bid Quoting at the top of the left rail. This opens Your spec books. Type in Find a spec book to find a book by number or name, then select Open. The pill on each book says where it is:

  • In progress: the run is still going.
  • Draft ready: the draft is ready to review.
  • Stopped: the run stopped before it made a draft. Select See what stopped.
  • Cancelled: the run was cancelled.

4Review the draft

Each draft line has a Product, Qty, Unit price, Line total and a Status that says what the line needs, for example Enter price, Enter footage, Confirm quantity or Confirm price. Select a product name to open its evidence panel on the right. The panel has three tabs:

  • Requirement: the spec text the line answers.
  • Price source: where the price came from.
  • Alternatives: other catalog products that came close. Select Pick this on one to put it on the line instead.

At the bottom of the panel, select Accept line when the line is right, or Flag for review to mark it for a second look. The status then reads Accepted or Flagged. Select the X at the top right of the panel to close it.

5Answer Needs your call

Needs your call in the left rail lists everything that waits on a person, in groups: Confirm match, Check the drawings, Enter footage, Confirm quantity and Enter price. Select a group heading to fold it, or use Collapse all and Expand all at the top.

  • On a near match, select Pick this to use the product shown, Search catalog to find another, or Skip to come back to it later.
  • On an item that is already a draft line, select Open to go to that line.

6Add lines from the drawings

Select Drawing counts in the left rail, then select Attach drawing PDF and pick the drawing set. The app counts the device labels it finds on the drawings.

  • Check the counts, then select Accept all. It accepts every row that waits for Accept. It leaves out existing and demolition rows and rows marked Needs review.
  • A row marked Needs review needs a person, often because the symbol is a single letter or the drawing legend does not name it. Select Accept or Reject on each of these rows.
  • Under Devices counted, when a card shows a From the drawings suggestion, select Add as new line to add that product to the draft with its count. If the product is already on the draft, the button reads Place counts on that line.
  • For any other device, pick its draft line in Pick the line these go on, or type in Type to filter lines, then select Place counts on line.
  • List and Map at the top switch between the table of counts and a view of where each device sits on the sheet.

7Check footage and prices

Select Draft lines in the left rail to go back to the draft.

  • A cable priced by the foot shows Enter footage. Type the measured footage in its Qty box, which shows ft. A cable line with no footage is left off the quote.
  • Type a price on any line whose unit price box reads Enter price.

8Create quote

In the bottom bar, select the Select an account box, type part of the account name and pick the account from the list. Until an account is picked, the bar reads Select an account to create the quote. Then select Create quote.

  • If a cable line still waits for its footage, the bar names it and asks first. Select Create without it (Create without them for more than one line) to leave it off, or Go back to type the footage.
  • The bar then reads Quote created., with Open the quote and Download CSV. The draft becomes read-only.

9The quote in Salesforce

Select Open the quote to open the quote in Salesforce. Select the Related tab, then View All on Quote Lines to see every line with its product, price and quantity. Make any later changes there, including a price that is still blank.

Good to know

  • Guided mode in the left rail turns a short guided walk through a draft on or off.
  • Settings, at the bottom of the left rail, has Text size (Small, Default, Large) and Appearance (Light, Dark, System). These two are saved in this browser only.
  • Each person sees only the spec books they uploaded.
  • Back to Salesforce, near the bottom of the left rail, leaves the app.
