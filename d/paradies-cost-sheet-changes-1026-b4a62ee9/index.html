2Promotional Products pricing Done

Asked“a box called “decoration method” ... a “Setup Price” ... a discount drop-down box ... a “Decoration/Run Charge” box ... This box is optional”Notes p. 3

Now: Enter the item price, Setup Price and Decoration/Run Charge as the supplier lists them, each with its own discount code from the ASI/PPAI chart (all 15 codes). The net shows beside each one. The setup price is divided by each tier's quantity. Decoration method is free text. Inbound freight is optional and is divided by the MOQ. Any part can be left empty.

Why there is an item priceThe notes add Decoration method, Setup Price and the Decoration/Run Charge. The item itself needs a price too, so the sheet starts with the item price and its code, the way the example on the 10/21 call and the workbook both start ($25.28 on C = $15.17).

7Digitizing toggle, on by default Done

Asked“a toggle for “Digitizing” like the one above ... toggled “On” by default ... need to be able to toggle it off”Notes p. 2

Now: Each embroidery line has a Digitizing switch. A new line starts with it on. Turning it off removes the charge.

8Digitizing price Done

Asked“Formula = stitch count rounded to the next 1,000 x $2.00 ... divided by the tiers/MOQ”Notes p. 2

Now: Full Package uses that formula, divided by each tier's quantity: 5,000 stitches = 5 x $2.00 = $10.00, or $0.07 a piece at 144. Contract sheets use the digitizing rates in the Contract price catalog: $40 a logo up to 15,000 stitches, then $5 for each 1,000 over.

9Infant sizes Done

Now: On Step 1, pick Infant as the core size range and enter one blank cost. That cost prices NB, 6M, 12M and 18M together, the same way Toddler works. Infant prints on the production copy and both PDFs.
