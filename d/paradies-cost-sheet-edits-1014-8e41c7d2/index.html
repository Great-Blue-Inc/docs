Not in the note. Each one applies your feedback in more places, or removes a number shown twice. None changes how a price is worked out. Each can be undone on its own: just say which.

S1DTF uses the same locations Suggested

WhyYour note asked to match the locations “across the board” (N17). Embroidery now matches Screen Print. DTF still had its own shorter list.

Change: DTF offers the Screen Print list, which adds Front Pocket and Spine. Location does not change a DTF price (its size does).

WhyYour note removed this card from the Full Package guide (N2). The Contract and Third Party guides still showed it.

Change: The card is gone from those two guides too. The sizes are still set in Quote details.
